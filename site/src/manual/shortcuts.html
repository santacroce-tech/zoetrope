Keyboard shortcuts

On Windows and Linux, use Ctrl where this page says ⌘, and Alt for ⌥. In the app, press ? to see this list.

File and edit

⌘S / ⇧⌘SSave / Save as
⌘OOpen
⌘IImport images
⌘Z / ⇧⌘Z or ⌘YUndo / Redo
?Show shortcuts

Everything you need for 2D animation

Vector drawing

Rectangles, ellipses, stars, lines, a Bézier pen and a smoothing pencil. Gradients, strokes and dashes, bitmaps, and precise anchor editing, with snapping, rulers and guides.

Timeline and tweens

Layers and folders, keyframes, motion and shape tweens with eased or custom Bézier timing, and onion skinning. Frame labels let scripts jump around.

Symbols that nest

Graphics follow their parent's timeline; movie clips run on their own clocks; buttons have Up, Over, Down and Hit states. Edit any of them in place.

Text and sound

Real typography (kerning, ligatures, wrapping) from fonts embedded in the project, so text looks the same everywhere. Event and stream sounds stay in sync with the timeline.

Scripting

Modern JavaScript with a familiar API: stop(), gotoAndPlay("label"), bee.x += 5, onEnterFrame, hitTestObject, Key.isDown. Scripts run sandboxed, so a bug can't hang the app.

Export anywhere

One self-contained HTML file that works offline, or a page plus an asset pack for big projects. Letterbox, fill or fixed scaling, and an embed snippet. It plays exactly like the preview, frame for frame.

Why it plays the same everywhere

Everything that decides what a frame looks like (the scene graph, tweens, text layout, the runtime, script semantics) lives in one Rust core compiled to WebAssembly. The editor's preview and every exported page run that same core, and every release checks frame-by-frame fingerprints between them.

Projects are plain, versioned JSON with your images, fonts and sounds embedded, so a file opens the same way years from now. Unsaved work is autosaved and offered back after a crash. Undo covers every operation.

# Changelog

## 0.2.0

- **Copy, cut and paste**, within a project and between projects. Symbols,
  images, fonts and sounds come along. Pasting the same thing again reuses
  them instead of making duplicates. ⇧⌘V pastes in place. Text and images
  from other apps paste as new text or bitmaps.
- **Native menus** on macOS, Windows and Linux, with the usual shortcuts.
- **Unsaved changes are never lost on close.** Closing the window or quitting
  asks to save first.
- **Open `.zoe` files from the OS**: double-click one in Finder or Explorer,
  or drop it on the app icon.
- **Mask layers.** A mask shows the layers inside it only where its shapes
  are. Animate the mask for reveals and spotlights. Projects are now saved
  as format version 7, and older files open as before.
- **A better script editor**: syntax colors, suggestions for the scripting
  API, your instance names and frame labels, and errors underlined as you
  type. Also smarter indenting, ⌘/ to comment lines, and undo while typing.

## 0.1.0

First release: vector drawing, timeline and tweens, symbols, text and sound,
sandboxed JavaScript scripting, and export to a single HTML file.

# Bundled font

`ZoetropeSans-Regular.ttf` is a subset (Basic Latin, Latin-1, Latin
Extended-A, common punctuation, €, ™) of **Lato 2.015 Regular** by Łukasz
Dziedzic (tyPoland), renamed because "Lato" is a Reserved Font Name under the
SIL Open Font License 1.1. See `OFL.txt`.

It is Zoetrope's default text font and is embedded into projects that use it.
